# ESP32 Chip-8 Emulator

Made for a school project.

## Useful commands

**Checking total amount of Non-Volatile storage on your ESP32:**

    esptool.py --port <port> flash_id

**View hexadecimal code in a .ch8 file:**

    hexdump -C <file>

> `-C` for using the endian type of the file not your own systems default
